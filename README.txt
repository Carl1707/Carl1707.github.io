我的数据小馆 - 个人主页基础版
===============================

打开方式
--------
直接双击 index.html 即可预览；将仓库推送到 GitHub 后，可通过 GitHub Pages 发布。

最需要先修改的内容
------------------
1. 打开 content.js，替换昵称、专业年级、三句简介和标签。
2. 将 data.entries 中的演示数据改成属于你本人的真实非负数数据，并同步修改标题、单位和观察文字。
3. 用你自己的照片或插画替换 assets/avatar-placeholder.svg，再在 content.js 中修改路径及图片描述。
4. 将彩蛋便签 messages 改成有你个人特色的梗或故事。

视觉客制化
----------
styles.css 顶部的 :root 是全站设计变量：
- --bg / --bg-shade：背景色
- --accent / --accent-deep：主强调色
- --blush：暖色点缀
- --radius-large / --radius-medium：卡片圆角

发布到 GitHub Pages
-------------------
仓库名为 Carl1707.github.io 时，将页面文件推送到默认分支后，一般可访问：
https://Carl1707.github.io

作业提醒
--------
本基础版已经包含自我介绍区、数据可视化区和可点击彩蛋区。
目前的数据与个人信息为可编辑示例，不应原样作为真实个人内容提交。
提交前请补充真实数据、成品截图、设计说明、关键 Prompt 记录与踩坑复盘 PDF。
